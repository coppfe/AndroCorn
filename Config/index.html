    Configuration Schema & Device Profiles

    In AndroCorn v2.0+, the configuration subsystem is strictly typed using Python dataclasses (androidemu.data.models). The old unstructured dictionaries and hardcoded "config" strings for am get-config have been eliminated.

    Configurations can be passed as a Python dict (such as DEFAULT_PACKAGE) or loaded directly from a JSON file.

    Dynamic Telemetry Generation

    1. am get-config Generation: The emulator dynamically computes the terminal output for /system/bin/am get-config using DisplayInfo.to_am_config(). No more manual string stitching!
    2. Deterministic Time: start_timestamp locks the system clock, ensuring all cryptographic hashing and token generation procedures are 100% reproducible.
    3. Telephony & Identity: Java calls to TelephonyManager.getDeviceId(), getSubscriberId(), and Settings.Secure.getString(..., "android_id") automatically reflect the profile.
